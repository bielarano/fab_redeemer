# Fab Redeemer

Automatically claim all free assets on [Fab](https://www.fab.com/) with a userscript manager such as **Tampermonkey** or **Violentmonkey**.

## Overview

Fab Redeemer is a lightweight browser userscript designed to help you quickly add free assets from Fab to your library.  
It is intended for personal use and aims to make the claiming process faster and more convenient.

## Features

- Automatically detects free assets on Fab
- Claims available free assets with minimal manual interaction
- Works directly in your browser
- Easy to install and use
- Compatible with popular userscript managers

## Requirements

Before using this script, make sure you have:

- A Fab account
- An active login session on [fab.com](https://www.fab.com/)
- A userscript manager installed in your browser

Supported userscript managers include:

- [Tampermonkey](https://www.tampermonkey.net/)
- [Violentmonkey](https://violentmonkey.github.io/)
- [Greasemonkey](https://www.greasespot.net/)

## Installation

1. Install a userscript manager in your browser:
   - Tampermonkey
   - Violentmonkey
   - Greasemonkey

2. Open the script file or install URL.

3. Confirm the installation in your userscript manager.

4. Make sure the script is enabled.

## How to Use

1. Log in to your account on [Fab](https://www.fab.com/).
2. Open the Fab page where the free assets are listed.
3. Let the script load.
4. Use the script panel or controls shown on the page.
5. Start the claiming process.
6. Wait until the script finishes adding the free assets to your library.

## Recommended Usage

For the best results:

- Filter Fab results to show only free assets
- Keep only one Fab tab running the script at the same time
- Do not interact too much with the page while the script is working
- Refresh the page if Fab changes its layout or stops responding correctly

## Troubleshooting

### The script does not start
- Check that your userscript manager is enabled
- Make sure the script is active
- Refresh the Fab page
- Verify that you are logged in

### Assets are not being claimed
- Confirm that the assets are actually free
- Check whether Fab requires a license selection
- Reload the page and try again
- Open the browser console to inspect possible errors

### The script stopped working after a Fab update
Fab may change its internal structure or API.  
If that happens, the script may need to be updated.

## Notes

- This script depends on how Fab currently behaves and may break if the website changes.
- Some free assets may still require a specific license selection before being added.
- Use responsibly and always review what is being added to your account.
